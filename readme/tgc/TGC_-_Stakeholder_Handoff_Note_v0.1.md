# TGC — Stakeholder Handoff Note v0.1

## 1. Project Centre

**That Game: Catalyst** is a multiplayer social world built around presence, communication, shared agency, and player-shaped civilisation.

The project is expressed through a third-person sci-fi civilisation sandbox, but its foundation is human socialisation.

Clean directional multiplayer sound, proximity-aware communication, environmental audio, group coordination, comfortable social spaces, and seamless collaboration are core infrastructure.

The product centre is:

> **A comfortable, expressive, socially alive frontier where players communicate naturally, shape the world together, and create shared history.**

---

## 2. How To Read The Pack

The documentation is organised in two layers:

1. **Fast-entry one-pagers** for quick stakeholder alignment.
2. **Full briefs** for design, technical, narrative, and production detail.

Start with the one-pagers, then move into the full briefs as needed.

---

## 3. Fast-Entry One-Pagers

### 3.1 TGC — One-Page Executive Summary

This is the first read.

It explains the project positioning, player experience, core differentiator, world and narrative frame, and first playable proof.

Read this when you need the fastest possible understanding of what TGC is and why it is different.

### 3.2 TGC — One-Page Experience Pillars

This is the decision-rule summary.

It explains the seven experience pillars that should guide design, architecture, audio, interface, multiplayer, world-building, narrative, and production decisions.

Read this when evaluating whether a feature, system, or prototype supports the project centre.

### 3.3 TGC — One-Page Vertical Slice Summary

This is the first playable summary.

It explains the proposed vertical slice, **The Relay Beneath the Ridge**, and the proof points required to demonstrate the foundation of TGC.

Read this when discussing scope, prototype priorities, or first playable expectations.

## 7. Consistent Project Language

Use this language consistently:

- TGC is a multiplayer social world.
- Communication is foundational infrastructure.
- Systems create reasons for players to interact.
- Building and environment systems create social places.
- Factions are social pressure systems.
- Narrative gives meaning to shared action.
- The vertical slice proves presence, communication, collaboration, and world response.

Avoid this framing:

- TGC is a game with many genres.
- TGC is mostly a story-driven sci-fi adventure.
- Voice chat is a feature.
- Factions are quest vendors.
- Lore is the main selling point.
- The vertical slice should show every major system.
- The game is differentiated by feature quantity.

---

## 8. Final Positioning

TGC succeeds when players stay in the world not only because there are objectives to complete, but because being there with others feels natural, useful, expressive, and meaningful.

That is the message the pack protects.
